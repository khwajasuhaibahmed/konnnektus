# 🌐 Konnnektus

A modern and responsive marketing agency website built to showcase Konnnektus's services, projects, team, and digital presence.

## 📌 About the Project

Konnnektus is a responsive marketing agency website designed to present the agency's services, portfolio, team, and organizational information through a modern web interface.

The website focuses on clean UI, responsive layouts, visual storytelling, and an engaging user experience.

## ✨ Features

- 📱 Responsive design
- 🏠 Modern landing page
- 💼 Services showcase
- 🎨 Project/portfolio showcase
- 👥 Team and organization sections
- 🖼️ Image-rich content sections
- 📩 Contact section
- ⚡ Interactive JavaScript components
- 📱 Mobile-friendly navigation

## 🛠️ Tech Stack

| Technology | Usage |
|---|---|
| HTML5 | Website structure |
| CSS3 | Styling and responsive design |
| JavaScript | Interactivity and functionality |
